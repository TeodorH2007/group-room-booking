# Grupp-rumsbokning

Ett projekt i TE4 för att skapa ett enkelt system där användare kan boka grupprum.

Projektet innehåller en frontend med HTML, CSS och JavaScript. Användaren kan välja rum, fylla i sina uppgifter och se sparade bokningar. JavaScript används bland annat för formulärvalidering, kontroll av lediga tider och lagring av bokningar i webbläsaren.
